# Busybar status

[English version](README.md)

Статус на [BUSY Bar](https://busy.app) (светодиодная лента 72×16 с колесом): что играет, что делают нейросети, сколько вы работали, ближайшая встреча и живы ли серверы. Колесо переключает экраны, кнопка **OK** листает страницы экрана, а большая центральная кнопка **Start / Pause** делает ещё одно дело на двух экранах (см. ниже).

Две части: JavaScript-приложение, которое работает **на баре**, и агент, который работает **на компьютере** (Node 24) и снабжает его данными. На Mac к агенту прилагаются значок в строке меню и страница настроек в браузере.

| Экран | Что показывает | OK / Start |
|---|---|---|
| Музыка | обложка 16×16 со скруглёнными углами, название и исполнитель (длинные прокручиваются), линия прогресса, которую бар двигает сам, по желанию значок play / пауза | Start: по желанию пуск и пауза |
| AI | токены и стоимость по ценам API текущего 5-часового окна Claude, время до сброса, токены за день (`D`) и неделю (`W`), линия «сколько окна прошло» и маскот (свой у Claude или радужное привидение): работает, как только любой агент начал работу, танцует, когда нейросеть закончила, моргает и спит. Запущено несколько агентов (Claude, Codex, Gemini, Aider, …)? | OK: следующий агент |
| Работа | вчера и сегодня («Сегодня» зелёным, пока вы работаете, жёлтым на паузе) | с какого времени и сколько подряд; квадраты активности за пять недель, как на GitHub, с итогами недели и месяца |
| Календарь | ближайшая встреча и отсчёт; за N минут до встречи всплывает поверх любого экрана | следующая встреча |
| Маскот | по желанию (включается на вкладке AI страницы настроек): только маскот по центру; пока агент работает, он радостно прыгает, а вокруг расходится сплошная синяя затухающая волна (пульс) | – |
| Серверы | скруглённая плашка со значком на каждый сервер (зелёная — в сети, серая — не отвечает); чем серверов больше, тем плашки меньше: значок уступает место первой букве, а потом одному цвету. Или список | OK: по одному серверу. Start: следующая страница списка |

У каждого экрана свой акцентный цвет, его можно сменить. Напоминания: встреча скоро, вы отработали N часов, пора на перерыв, сервер упал, нейросеть закончила.

## Быстрый старт (macOS)

Нужны macOS 13+, Node 24 (`nvm use` берёт версию из `.nvmrc`), инструменты командной строки Xcode (`xcode-select --install`, для `swiftc`), [`media-control`](https://github.com/ungive/media-control) для экрана музыки (`brew install media-control`) и BUSY Bar в той же сети Wi-Fi.

```sh
git clone git@github.com:solowey1/busybar-status.git && cd busybar-status
nvm use && npm ci
npm run build                                   # приложение для бара -> dist/app.solowey.busybar-status.tgz
npm run app:install -- --addr <ip бара> --password <пароль бара>
npm run app:run     -- --addr <ip бара> --password <пароль бара>
(cd mac-agent && ./tray/install.sh)             # собирает и запускает приложение в строке меню и агента
```

Дальше: значок в строке меню → **Настроить…** (страница `http://127.0.0.1:8787/ui`). На вкладке **Общее** введите адрес бара и пароль, нажмите **Привязать** (в приложение на баре запишутся IP Mac, порт и токен) и **Сохранить**. macOS один раз спросит, можно ли читать календарь.

Готовые пакеты для macOS, Windows и Linux лежат в каждом [релизе](https://github.com/solowey1/busybar-status/releases) (см. [Пакеты](#пакеты)). Убрать приложение из строки меню: `mac-agent/tray/install.sh uninstall`.

## Настройки

**На баре** (Настройки → приложение): язык (Русский / English), IP Mac, порт и токен, а также переключатель для каждого из пяти экранов. Больше ничего: страница настроек самого бара плоская и маленькая, подписи на ней на двух языках.

**В браузере** (`/ui`, из значка в строке меню): всё остальное, по вкладке на экран. Изменения сохраняются на Mac и доходят до бара за несколько секунд.

| Вкладка | Настройки |
|---|---|
| Общее | адрес и пароль бара, **Привязать**; **язык всего приложения** (бар, эта страница, меню в строке меню, уведомления; применяется сразу); запуск при входе; показывать приложение в Доке / строке меню / в обоих местах / нигде; имя `.local` для этой страницы (но не `busybar`: так называется сам бар); вид значка в строке меню |
| Музыка | обложка и её непрозрачность; значок play / пауза (зелёный, на паузе жёлтый); большая кнопка **Start / Pause** пускает и ставит на паузу; акцентный цвет (на паузе полупрозрачный) |
| AI | **отдельный экран с маскотом**; **агент по умолчанию**; маскот: Claude, привидение или без маскота (привидение достаётся и другим нейросетям, когда они сообщают о конце работы); **перекрывать другие экраны при завершении** (по умолчанию выключено: тогда сообщают только звук и светодиод, а новость ждёт на экране AI); акцентный цвет |
| Работа | напоминание через N часов; перерыв каждые N минут; сколько дней хранить (30); сколько простоя считать паузой; акцентный цвет; квадраты активности |
| Календарь | за сколько минут показывать встречу; какие календари не учитывать; акцентный цвет (по умолчанию красный) |
| Серверы | список (название, адрес, значок, цвета; порядок меняют стрелки); плашки или список (в списке большая кнопка листает страницы); цвета «в сети» / «не отвечает» |
| Приложение | автолистание, прятать пустые экраны, сколько держать название экрана после поворота колеса (700 мс, 0 — не показывать), звук уведомлений |

Страница настроек удобна и на телефоне (тот же адрес в той же сети, ссылка с токеном есть на вкладке «Общее»): вкладки превращаются в полосу сверху, строки встают в столбик.

Если выбрать показ **нигде**, настройки останутся доступны по адресу в браузере (`http://127.0.0.1:8787/ui`, а при заданном имени ещё и `http://<имя>.local/ui`: пока имя задано, страница слушает и порт 80, так что `:8787` не нужен). Браузер, который страницы ещё не видел, один раз спросит токен (на вкладке «Общее» есть готовая ссылка с ним). Имя публикует в локальной сети macOS (Bonjour); `busybar` не принимается, потому что `busybar.local` — это сам бар.

## Приложение в строке меню (macOS)

Щелчок по значку (радужное привидение; другие варианты на странице настроек) открывает меню: состояние агента и порт, адрес бара, доступ к календарю, **Настроить…**, **Перезапустить** и **Отключить** (останавливает и агента). Агент запускается как дочерний процесс приложения и поднимается снова, если упал. Запуск при входе — переключатель на странице настроек, его выполняет macOS как элемент входа (Системные настройки → Основные → Объекты входа); пока вы не включили, ничего не устанавливается.

Календарь читает само приложение, поэтому разрешение принадлежит ему, а не терминалу, из которого что-то запущено. После пересборки приложения macOS может спросить снова.

## Уведомления от нейросетей

Хук сообщает бару, что нейросеть закончила. Для Claude Code добавьте в `~/.claude/settings.json`:

```json
{
  "hooks": {
    "Stop": [{ "hooks": [{ "type": "command", "command": "node /ПУТЬ/mac-agent/bin/notify.mjs claude_done" }] }],
    "Notification": [{ "hooks": [{ "type": "command", "command": "node /ПУТЬ/mac-agent/bin/notify.mjs claude_wait" }] }]
  }
}
```

Бар узнаёт, что агент работает, примерно за секунду и без хуков: агент на Mac следит за процессами агентов (нагрузка процесса и того, что он запустил), их журналами сессий и хуками. Хук делает это точным: добавьте `UserPromptSubmit` → `node /ПУТЬ/mac-agent/bin/notify.mjs claude_start` для начала (без всплывающего окна), а хук `Stop` выше сразу ставит конец. Несколько агентов сразу (Claude, Codex, Gemini, Aider, OpenCode, Cursor, Goose) перечислены на странице настроек; **OK** на экране AI переключает их, а в настройках выбирается, какой показывать первым. Токены и стоимость есть только у Claude, у остальных видно состояние. Любой другой инструмент (Codex, Gemini, скрипт) может вызвать `node mac-agent/bin/notify.mjs ai_done "Codex: проект"` и `ai_wait`. Токены и стоимость берутся из логов Claude Code в `~/.claude/projects`. Стоимость — это сколько те же токены стоили бы по ценам API (`PRICES` в `mac-agent/src/sources/claude.mjs`), а не расход по вашей подписке.

## Время работы

Агент каждые 15 секунд смотрит, сколько прошло без клавиатуры и мыши, и складывает активное время по дням в `~/.local/state/busybar-status/work.json` (последние N дней, по умолчанию 30). Считает он только пока работает и Mac не спит, так что для целых дней включите запуск при входе.

## Пакеты

В каждом релизе есть архивы `busybar-status-<версия>-<система>` для `darwin-arm64`, `darwin-x64`, `linux-x64`, `linux-arm64` и `win-x64`. В каждом свой Node и `.tgz` приложения для бара.

| Система | Что внутри | Чего нет |
|---|---|---|
| macOS | `Busybar status.app` со значком в строке меню (подпись ad-hoc, без нотаризации: в первый раз откройте правым щелчком → Открыть) | – |
| Windows, Linux | агент и `start.cmd` / `start.sh`, которые запускают его и открывают страницу настроек | приложения в строке меню, музыки и календаря; время работы на Linux требует `xprintidle` или GNOME |

Собрать самому: `npm run build && node mac-agent/tools/package.mjs <система>` (пакеты для macOS собираются на Mac). Пакеты для Windows и Linux собирает релизный workflow, на этих системах автор их не запускал.

## Как это устроено

```
компьютер: агент (Node 24) <--- HTTP раз в 3 с, крошечный ответ, если ничего не изменилось ---> бар: JS-приложение
  media-control, логи Claude Code, простой ввода, EventKit (через приложение в строке меню), ping серверов
```

Приложение на баре не принимает входящих соединений и на прошивке 1.3.1 не может писать в хранилище, поэтому оно само обращается к агенту. Агент хранит номер ревизии и держит каждый запрос до двух секунд, пока ничего не изменилось (долгий опрос), так что новость доходит до бара в тот же момент. Прогресс трека, время работы и отсчёты бар считает сам; бегущую строку и `countdown` рисует прошивка. На дисплей уходят только изменившиеся элементы. Настройки экранов приходят в том же ответе.

`~/.config/busybar-status/config.json` (закрыт для остальных, правится со страницы настроек): порт, токен, адрес и пароль бара, серверы, игнорируемые календари, значок и выбор Дока, имя `.local`, переключатель запуска при входе и `settings` экранов (см. `mac-agent/src/appsettings.mjs`).

## Разработка

```sh
npm run typecheck             # приложение для бара
npm run build                 # приложение для бара -> dist/
(cd mac-agent && npm test)    # агент: 23 теста
node mac-agent/tools/icons.mjs appmeta src/appmeta   # перерисовать иконки-привидения для бара
```

`src/` — приложение для бара (TypeScript, строгий режим, работает в JerryScript прошивки, не в Node; куча в манифесте 512 КиБ, а буферы экран держит, только пока он на дисплее, а её нехватка перезагружает весь бар, так что держите выделение памяти на кадр небольшим), `mac-agent/` — агент: `src/` исходники, `ui/` страница настроек, `tray/` приложение в строке меню (Swift), `tools/` иконки и упаковка. Значки плашек серверов — светодиодные 9×9 версии иконок [Lucide](https://lucide.dev) (лицензия ISC), их делает `mac-agent/tools/glyphs/raster.py` в `src/glyphs.json` (одна строка из 81 символа на значок); кнопки на странице настроек тоже используют иконки Lucide. Перед правкой приложения для бара прочитайте `AGENTS.md`.

Справка по шаблону BUSY (сборка, манифест, ресурсы) — в [английском README](README.md#busy-app-template-reference).
